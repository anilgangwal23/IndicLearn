# indic_learn

A Flutter app for learning Indian languages through scenario-based lessons:
vocabulary, pronunciation, phrases, and sentence-building games.

- **Agents and contributors:** start with [AGENTS.md](AGENTS.md) for commands and conventions.
- **Architecture:** [docs/architecture/](docs/architecture/) covers the theme, level selection, and accounts.
- **Accounts setup:** [docs/accounts.md](docs/accounts.md).
- **SVG layer contract and mascot animations:** [lib/ui/README.md](lib/ui/README.md).
